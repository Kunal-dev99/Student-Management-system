# 10 · Completion & alumni — record the award, set classification, graduate

## What it is

The corrections closed. The **Record award** button unlocked. In this chapter we record Priya's degree award (the second "award" — the graduation one, not the funder's), set the classification, generate the certificate reference, and watch her record move from "Progressing" to "Graduated". The same row that started this demo as a research grant now closes as an alumnus.

## The clicks

**Step 01 · Open Completion for Priya.**
- **WHERE** — Sidebar → **Completion** (award icon) → filter by Priya Nair.
- **DO** — See her pending completion row.
- **SEE** — Row with an amber "Ready for award" pill; **Record award** button available.
- **SAY** — *"Priya's ready. Corrections closed, viva outcome recorded. The completion queue picks her up automatically."*

**Step 02 · Record the award.**
- **WHERE** — Click Priya's row → **Record award**.
- **DO** — Fill form: award date today, degree `PhD`, thesis title (auto-filled), certificate reference `UBAI-PHD-2031-0142`.
- **SEE** — Fields validate; certificate reference is unique-checked.
- **SAY** — *"The degree award is one form. Once recorded, the workflow moves to classification."*

**Step 03 · Set the classification.**
- **WHERE** — Same page → **Classification** section.
- **DO** — Fill: outcome `Pass`, rationale paragraph, examiner attribution. Save.
- **SEE** — Classification card populates. Status pill flips to green "Graduated".
- **SAY** — *"Classification with rationale — auditable, exportable, immutable."*

**Step 04 · See Priya move to Alumni.**
- **WHERE** — Priya's person page → **Timeline**.
- **DO** — Point at the new **Alumni** segment starting today.
- **SEE** — Timeline: Applicant → Student → Alumni. Same person, same record, four years of history intact.
- **SAY** — *"The row that started as an applicant closes as an alumna. Same record all the way through."*

**Step 05 · Close the loop back to the award.**
- **WHERE** — Same page → **Funding lineage**.
- **DO** — Point at the tree: the EPSRC award at the top now shows "1 studentship completed".
- **SEE** — The award's completion counter went up by one.
- **SAY** — *"The upstream grant knows one of its studentships has graduated. Full-circle. From funder's grant to graduated student, all one arc."*

## The line

The row that started as an applicant closes as an alumnus — same record, same audit trail, all the way through.
