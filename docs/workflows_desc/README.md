# PGR workflows — descriptions

One markdown file per cycle. Each file is the same shape:

- **What it is** — one paragraph of context.
- **The clicks** — numbered steps in a `WHERE / DO / SEE / SAY` block. WHERE names the sidebar item or panel; DO is the literal action; SEE is what confirms it worked; SAY is what to say out loud in a demo.
- **The line** — one sentence to land before moving on.

Read them individually before a demo of that cycle; read the whole folder for the full tour. `_ALL_workflows.pdf` is every workflow bound into one PDF with a page break between them.

## Terminology heads-up

"Award" means two things in PGR — the **research award** at the top of the arc (a funder gives the institution money) and the **degree award** at the end (the student graduates). Both are covered by their own workflow doc; keep them separate in your head when a buyer asks about "awards".
